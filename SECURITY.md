# Security policy

Please report vulnerabilities privately through the repository's security advisory feature or the maintainer contact listed in the repository settings. Do not open a public issue for an SSRF, redirect, upload, authentication, data-exposure, or dependency finding. Include reproduction steps, impact, affected version or commit, and any safe proof of concept. Acknowledgements are made after a fix is available.

This policy applies to the current `main` branch. Do not include real credentials, URLs containing personal data, or harmful payloads in a public report.

SecureLink is an inspection aid, not a replacement for endpoint protection or incident response.
